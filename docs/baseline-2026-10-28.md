To reproduce this isolated launch after stopping the existing server, from the app repository:

```sh
NEXT_TELEMETRY_DISABLED=1 LH_IGNORE_ENV_KEYS=1 \
LH_DATA_DIR=/tmp/research-atlas-baseline/interactive-data \
LH_AUTH_FILE=/tmp/research-atlas-baseline/interactive-auth.json \
npm run dev -- --hostname 127.0.0.1 --port 3005
```

This is a disposable baseline instance. Durable personal use should use a deliberately chosen persistent data directory and provider setup.
