# Concept-to-derivation navigation

Atlas → concept → **Derivations** opens the shared canonical map and highlights the entry concept’s linked claims. Select a claim for its exact statement, recorded arguments, complete joint premises, and source locations. Alternative arguments stay distinct. The accessible claim list works without Canvas. Inspecting, highlighting, and fitting preserve saved placements and never call an agent.

The bounded map prioritizes the entry concept’s backward slice, then adjoining proof families. It shows up to 150 claims and 80 arguments with a visible truncation notice. Additional arguments are omitted whole. Broken references are omitted and missing concept links are shown as unavailable. Canonical IDs appear once. The ledger records arguments and provenance. Formal verification and learner mastery are separate.

## Link and learn

**Link an existing claim** searches names, statements, and aliases. The owner picks an exact ID and confirms the revision-checked link. This preserves notes, positions, and canonical records. With an empty Library, the app offers **Start a derivation lesson** without synthesizing canonical claims.

**Learn this step** carries the concept, linked root, selected target, and optional argument into a lesson. Before creating the chat, the server validates that the target is reachable in the bounded canonical slice. The context retains the exact argument and every joint premise. A claim outside the slice can be inspected and linked explicitly. It cannot silently substitute for the selected target.

Lesson-review derivations use the same visual grammar for draft claims. Unapproved draft keys stay separate from canonical IDs. Gaps appear in the explanation, never as inference arrows. See [reviewed lesson integration](atlas-lesson-integration.md).

## Shared proof layout

Terminal results occupy the center, with earlier premises on outer rings. Shared prerequisites retain one position in a result’s sector. Bounded force settling clears labels and deterministic anchors handle cycles and disconnected claims. Sector colors distinguish proof families visually. Conjunction junctions stay distinct from claim dots.

The compact overview folds a repeated premise link when the earlier argument path already carries it. Mutually dependent premises are never folded on the basis of a cycle. The complete joint premise set stays in the ledger and step panel. **All premise links** restores the full diagram without moving its nodes. Selection restores cross-sector references for the focused argument.
